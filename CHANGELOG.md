# Changelog

All notable changes to the Reliant Landing Page are documented here.
Versioning follows [Semantic Versioning 2.0.0](https://semver.org/).

## [2.1.0] - AV2 (Semana 12)

### Added
- New visual identity: Poppins typography, navy/orange palette, Reliant logo, hero photography and icon cards.
- Services, Plans, About us (About the Product / About the Team videos, mission, vision, values) and Contact sections.
- "Sign in" and "Get started" actions in the header; footer with contact details, social links and legal navigation.
- Open Graph metadata.

### Changed
- All calls to action now open the Reliant Web Application sign-up with the matching organization type (`RECUPERATION_SUPPLIER` / `ASSET_OWNER`) instead of a placeholder URL.
- Copy rewritten around HVOF thermal-spray process monitoring, traceability, fault diagnosis and reporting (EN/ES).
- "How it works" steps aligned with the web application flow.
- Legal pages share the new header, typography and footer.

## [2.0.0] - TB1 (Semana 8)

### Added
- English and Spanish internationalization (i18n) for the landing page and legal pages.
- Language switcher (EN/ES) that remembers the visitor's choice and defaults to the browser language.

## [0.1.0] - AV1 (Semana 4)

### Added
- Initial landing page markup (hero, value proposition, segments, how it works, footer).
- Mobile-first responsive styles.
- Mobile navigation and segment-aware call-to-action behavior.
- Terms & Conditions and Privacy Policy pages.
